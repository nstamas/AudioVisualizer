## 🎵 Project Overview

A powerful desktop application featuring:
- **Real-time audio visualization** with ProjectM integration
- **Customizable patterns** and color gradients
- **Video recording** to industry-standard formats (MP4, AVI, MOV)
- **Sprite injection** with images, GIFs, and videos
- **Advanced effects**: masking, outlines, shadows, smearing, blur, bloom
- **User-friendly GUI** built with Dear ImGui

## 🚀 Key Features Implemented

### Core Systems
- **AudioEngine**: PortAudio integration with FFT analysis and beat detection
- **VisualizationEngine**: ProjectM integration for psychedelic visuals
- **VideoRecorder**: FFmpeg-based recording with multiple codec support
- **Application**: Main loop, lifecycle management, component coordination

### Graphics Pipeline
- **Renderer**: OpenGL 4.3 rendering with framebuffer management
- **SpriteManager**: Load and animate images, GIFs, videos
- **EffectsProcessor**: Post-processing effects (8+ effect types)
- **ShaderManager**: Custom GLSL shader support

### User Interface
- **MainWindow**: Menu bar, file operations
- **ControlPanel**: Real-time parameter control
- **PresetManager**: Browse and load visualization presets

## 🛠️ Technology Stack

- **C++17** with modern features
- **ProjectM** for music visualization
- **FFmpeg** for video encoding
- **PortAudio** for audio input
- **OpenGL 4.3** for rendering
- **Dear ImGui** for UI
- **GLM** for mathematics
- **CMake** for cross-platform builds

### 2. Download Third-Party Libraries
- **Dear ImGui**: https://github.com/ocornut/imgui

### 3. Build the Project
```powershell
mkdir build
cd build
cmake .. -DCMAKE_TOOLCHAIN_FILE=C:\vcpkg\scripts\buildsystems\vcpkg.cmake

```
